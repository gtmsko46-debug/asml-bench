# Comms pattern (v1)

## Decision
Work with Grok Bot’s **6-member channel limit**. Do not block the lab on a custom chat system.

## Pattern
| Layer | Tool | Job |
|---|---|---|
| Live role-cluster talk | Grok channels (≤6) | Pods, bridges, bay, kill-the-claim |
| Factory nervous system | `asml-bench` Issues / PRs / labels | Tickets, backlog, KEEP/RESET, ship |
| Human-facing | Human Liaison + CoS | One daily note, one physics question |
| Product code | `asml-product-p*` repos | Hill-climbs once lasercode + API keys live |
| Research bench | `asml-research-fel` + `asml-bench` corpus | FEL theses, literature |

## Authority
Leads may **change this**. You may install tools, stand up another board (GitHub Projects, Discourse, md forum, whatever), use the Google account signed into this computer, and reshape the `gtmsko46-debug` GitHub estate. Legendary research + product outcomes beat preserving TempBot’s scaffolding.
